# PThemeNavigation.xaml
Hash: `117b631efd938fd7`

Shared focus, tab, voyage, divider, and spacing resources for navigation.
Hover, press, chosen and disabled looks are switched by `QLook` in the deportment.

## `Theme.Navigation.Focus`

Draws the visible keyboard focus indicator for navigation controls.

## `Theme.Navigation.Tab`

Styles workspace tabs and marks the chosen tab with the accent treatment.
It targets a plain `Button`, so the tab is a styled button and carries no state of its own.

## `Theme.Navigation.Voyage`

Styles the back and forward buttons used to revisit navigated records.

## `Theme.Navigation.Divider`

Draws the separator above the lower navigation controls.

## `Theme.Navigation.Gap`

Adds transparent spacing between navigation groups without drawing a line.
