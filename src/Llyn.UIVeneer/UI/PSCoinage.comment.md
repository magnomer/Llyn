# PSCoinage.xaml

The dialog New opens when nothing in the taxonomy or tenor panel is chosen.
A Tag or a Register is only a name, so an editor for one would hold one field.
The message says which of the two is being named.
The field takes the wording, and the mint button stays dark until something is typed.
Escape and the retreat button leave without making anything.
The buttons wear the editor's own command styles, so the dialog reads as part of the program.
