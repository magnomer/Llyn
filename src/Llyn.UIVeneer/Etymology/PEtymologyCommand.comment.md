# PEtymologyCommand.cs

## `public static class PEtymologyCommand`

The commands the etymology field raises, bound by whichever side of the shell draws it.

## `public static RoutedCommand PEtymologyCommandLink`

Links the selected words of the narrative to an entry.

## `public static RoutedCommand PEtymologyCommandUnlink`

Drops the span under the caret.

## `public static RoutedCommand PEtymologyCommandAddition`

Takes the typed word as a new source link.

## `public static RoutedCommand PEtymologyCommandRemoval`

Drops the source link the chip names.

## `public static RoutedCommand PEtymologyCommandEntry`

Opens the entry the chip names.
