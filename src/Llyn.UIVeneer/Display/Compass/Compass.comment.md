# Compass

This folder holds the floating contents column of the entry page.
It stands apart from the page because the row answers a click the panel handles.
The display page merges this markup in its own resources and hands the click to [QCompass](../../../Llyn.UIDeportment/Display/QCompass.comment.md).

## `PDisplayCompass.xaml`

`Theme.Compass.Choice` is one heading, lit under the pointer and accented while its section is in view.
It is a button, because the row scrolls the page to the section it names.
`Theme.Compass.Number` shows the heading number at a fixed width so the names align.
It collapses when the heading carries no number.
`Theme.Compass.Row` indents by heading depth and trims the name to one line.
The display fills its named parts and marks the current row `Chosen`.
