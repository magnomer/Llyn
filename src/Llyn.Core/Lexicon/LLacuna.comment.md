# LLacuna.cs

## `public sealed record LLacuna(`

One slot of an entry's paradigm the web was asked for and could not fill.
A found form is stored as an inflection, so only the negative answer needs a record of its own.
It is kept in the workspace, so a reopen never asks the web again for a form no source named.
An entry no source could be reached for is one lacuna with no morphology, standing for the whole entry.
A hand edit of the entry's inflections deletes its lacunae, since the user's word replaces the source's.

**Parameters**

- `LLacunaEntryId` — The entry whose slot went unfilled.
- `LLacunaMorphologyId` — The morphology value a reached source could not name, or `null` when no source was reached.
- `LLacunaFetchedUtc` — Moment the web was asked, ISO 8601 UTC.
