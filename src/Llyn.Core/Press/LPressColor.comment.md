## `public enum LPressColor`

The colour mode sent to the printer.
The preview greys its pictures itself, so this never changes the drawn pages.

- `LPressColorDefault`: whatever the printer does by default.
- `LPressColorFull`: print in colour.
- `LPressColorGray`: print in shades of grey.
