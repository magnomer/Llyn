## `public enum LPressScope`

Which pages print, as the mode the reader picked.
Only the custom mode reads the typed range text.

- `LPressScopeAll`: every page of the proof.
- `LPressScopeCurrent`: the one page the canvas shows.
- `LPressScopeCustom`: the pages the reader typed as range text.
