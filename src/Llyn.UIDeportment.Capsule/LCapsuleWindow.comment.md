# LCapsuleWindow.cs

## `public sealed record LCapsuleWindow(`

The main window's restored rectangle and whether it stood maximized.

**Parameters**

- `LCapsuleWindowLeft` — The left edge of the restored rectangle.
- `LCapsuleWindowTop` — The top edge of the restored rectangle.
- `LCapsuleWindowWidth` — The width of the restored rectangle.
- `LCapsuleWindowHeight` — The height of the restored rectangle.
- `LCapsuleWindowMaximized` — Whether the window stood maximized when it closed.
