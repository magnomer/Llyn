# PExampleTemplate.xaml

## `Theme.Example.Row`

The Example row as the card shows it: the sentence field, the id the row will be stored under standing at the field's right, the number the row takes while the card carries more than one, the Source button, and the buttons that open and drop rows. The field's hint reads the unreadable mark when the row holds a sentence it cannot read back, so an empty-looking field says which kind of empty it is.

## `Theme.Reference.Row`, `Theme.Reference.Item`

One Source in the list a row cites from, and the row it sits in. Both are offered to the Situation rows as well, which is why they live in this dictionary rather than beside a single template.

## `Theme.Example.Identity`

The box the row's id stands in, hidden until the row has an id.

## `Theme.Example.Order`

The number ahead of the field, standing in the label column's gutter so an Example field starts exactly where every other field on the card does whether or not the rows are numbered.

## `Theme.Example.Citation`

What the Source button reads: the cited Source's name, the invitation to assign one when the row cites none, and the unreadable mark when the citation cannot be read back.

## `Theme.Example.Notice`

The line shown in the Source list while the workspace holds no Sources at all.
