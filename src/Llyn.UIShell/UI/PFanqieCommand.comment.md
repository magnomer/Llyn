# PFanqieCommand.cs

## `public static class PFanqieCommand`

The routed commands the fanqie line's links raise, bound by the fanqie box itself.
Each carries the line as its parameter, because the template has no code of its own.

## `public static RoutedCommand PFanqieCommandInitial { get; }`

Opens the rime table on the line's initial.

## `public static RoutedCommand PFanqieCommandRime { get; }`

Opens the rime table on the line's rime.
