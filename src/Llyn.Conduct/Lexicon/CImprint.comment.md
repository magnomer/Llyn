# CImprint.cs

## `public sealed record CImprint(`

The stated fields of the Source draft, as the imprint writes them into its fields.

**Parameters**

- `CImprintTitle`: the title as written.
- `CImprintTitleHint`: the resource key of the title field's hint.
- `CImprintYear`: the year as written.
- `CImprintYearHint`: the resource key of the year field's hint.
- `CImprintUrl`: the address as written.
- `CImprintUrlHint`: the resource key of the address field's hint.
- `CImprintNote`: the note as written.
- `CImprintNoteHint`: the resource key of the note field's hint.
- `CImprintKindKey`: the resource key of the kind's name.
- `CImprintKindTag`: the kind's tag, which marks its entry in the kind menu.
