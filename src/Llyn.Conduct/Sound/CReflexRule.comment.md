# CReflexRule.cs

## `public sealed record CReflexRule(string CReflexRuleLanguage, bool CReflexRuleFolded);`

One reflex rule, cut to what the display reads to fold its reflex rows.

**Parameters**

- `CReflexRuleLanguage`: the language the rule looks reflexes up in.
- `CReflexRuleFolded`: whether that language's rows start folded.
