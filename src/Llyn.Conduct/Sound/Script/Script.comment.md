# Script

This folder holds the script block of the stored entry and the forms of one character in one style.

## `CScriptGroup`, `CScriptImage`

The forms of one character in one style, and one historical form.
The epoch is a wording key, or empty when the era has no wording.

## `CSoundingScript`

The script block of the editor for the stored entry.
It carries its groups, a pending flag, a rebuildable flag and the pack's glyph font.
