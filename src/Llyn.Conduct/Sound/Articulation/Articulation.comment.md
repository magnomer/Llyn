# Articulation

This folder holds the IPA charts of the input aid, read one at a time or both in one go.

## `CArticulation`, `CArticulationAid`

One IPA chart of the input aid, and both charts read in one go.
The shape carries headers, sides and cell alternatives together, so the input aid receives chart data rather than parsing text.
