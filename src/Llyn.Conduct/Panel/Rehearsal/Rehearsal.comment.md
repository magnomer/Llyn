# Rehearsal

This folder holds the flashcard tab placeholders.
Its subfolders hold the deck, cue, stencil and export gates.

## `CStudy`

The study tab's placeholder, whose design is still open.
It names the empty line `Study.Empty`, since an empty-state key is interaction.
It registers no tab, because it has no leave question, station or arrival yet.

## `CScoreboard`

The statistics tab's placeholder, shaped as `CStudy`.
It names the empty line `Scoreboard.Empty` and registers no tab.
