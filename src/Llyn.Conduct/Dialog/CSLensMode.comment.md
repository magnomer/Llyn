## `public enum CSLensMode`

How the preview zoom follows the window.
A fitting mode recomputes the factor whenever the view or the paper changes.

## `CSLensModeWidth`

The page width fills the view width.
It is the mode a new print window opens in.

## `CSLensModePage`

The whole page fits the view, the smaller of the width and height ratios.

## `CSLensModeFree`

The factor stays as typed or stepped, whatever the view does.
