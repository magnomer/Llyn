# CMarkupTarget.cs

## `public sealed record CMarkupTarget(long CMarkupTargetId, int CMarkupTargetMeaning, int CMarkupTargetCollocation)`

One stored entry an imported entry may join, as the customs gate holds it.
No driver reads it, since the gate turns it into a row's ready loss.
Its card counts arrive ready, so the gate words a replacement's loss without reading the engine.

**Parameters**

- `CMarkupTargetId`: the stored entry's id.
- `CMarkupTargetMeaning`: the meaning cards a replacement drops, nested cards counted.
- `CMarkupTargetCollocation`: the collocation cards a replacement drops, nested cards counted.
