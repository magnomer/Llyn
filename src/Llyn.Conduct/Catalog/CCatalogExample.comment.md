# CCatalogExample.cs

## `public sealed record CCatalogExample(`

One example a search found, as the anthology lists it.

**Parameters**

- `CCatalogExampleId`: the stored example.
- `CCatalogExampleText`: the text as the row shows it, worded when unknown or unwritten.
- `CCatalogExampleName`: the text as the search matches it.
- `CCatalogExampleLanguage`: the language the example is written in.
- `CCatalogExampleCount`: the ready usage text, blank while no card quotes the example.
- `CCatalogExampleChosen`: whether the vista has this example chosen.
