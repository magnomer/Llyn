# CVistaRow.cs

## `public sealed record CVistaRow(`

One entry a search found, as the prospect popup and the panels' entry lists show it.

**Parameters**

- `CVistaRowId`: the stored entry.
- `CVistaRowHeadword`: the entry's headword.
- `CVistaRowLanguage`: the entry's language.
- `CVistaRowEpithet`: the entry's epithet, empty when it has none.
- `CVistaRowName`: the language's display name.
- `CVistaRowChosen`: whether the listing's vista has this entry chosen.
