# PImageHost.cs

## `internal interface PImageHost`

What a picture row's template asks of whoever drew it.
That is a file chosen and a row dropped.
The template is one dictionary, and the entry editor and the situation editor both fill it.
Each answers the two clicks in its own way, so the template speaks to a seam and not to either.
Adding a row is not here, because the button that adds one stands outside the template.
