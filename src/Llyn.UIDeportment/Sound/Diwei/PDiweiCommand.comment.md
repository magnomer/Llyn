# PDiweiCommand.cs

## `public static class PDiweiCommand`

The routed command the character chips of a category page raise, bound by the page itself.
It carries the character as its parameter, because the template has no code of its own.

## `public static RoutedCommand PDiweiCommandEntry { get; }`

Opens the entry one character chip stands for, making it first when none exists.

## `public static RoutedCommand PDiweiCommandSwitch { get; }`

Picks the set the tally lines print, raised by either half of the switch every division heading repeats.
Its parameter is `true` for the respelling half and `false` for the IPA half.
