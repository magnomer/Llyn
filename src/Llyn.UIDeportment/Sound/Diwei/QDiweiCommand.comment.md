# QDiweiCommand.cs
Hash: `97c3bc8ee506d7e0`

## `internal static class QDiweiCommand`

The routed commands the chips and switches of a category page raise, bound by `QDiwei`.
They carry their value as the parameter, because the template has no code of its own.

## `public static RoutedCommand QDiweiCommandEntry { get; }`

Opens the entry one character chip stands for, making it first when none exists.

## `public static RoutedCommand QDiweiCommandSwitch { get; }`

Picks the set the tally lines print, raised by either half of the switch every division heading repeats.
Its parameter is `true` for the respelling half and `false` for the IPA half.
