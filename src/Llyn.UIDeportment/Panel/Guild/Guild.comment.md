# Guild

The authors panel is the workspace browsed by the people its Sources credit.
It is the sources panel's shape read through a different question, so it holds the same three columns.
Every decision lives in Conduct's `CGuild`, and these drivers write controls on notice.

## `QGuild`

The roll is served here, and the oeuvre, the vita and the autograph have drivers of their own.
The rail, the order picker and the kind filter are shared drivers, built here and fed from Conduct.
It is the chronicle host its own rail walks, so the rail's undo and redo reach the session.
It registers no surface with `QChronicle`, because only its rail asks it to walk.

### `QGuild`

The rail has Fresh shown and Portrait hidden, since no Entry is read here.
The order picker hangs its menu under the whole `PEchelon` bar.

### `QGuildIntroduce`

Only the medium knows its dispatcher, so the marshal the area runs its notices through is built here.
The panel attaches its autograph desk's bulletins and its vista observers.
The roll's aperture feeds both the order picker and the kind filter.
The print command binding is added last, so no can-execute query ever meets a panel not yet built.

### `QGuildVistaRefine`

It only paints.
The roll is read once, and that answer carries the kind menu too.
The oeuvre answers the same opening with its own Refine.
The window subscribes the colophon's tally to the same opening after it.
The search fields keep their text, since Conduct carried the queries into the fresh vistas.

### `QGuildClose`

Both pickers' menus close, so nothing stays open over a window that is going.

### `QGuildShownCheck`

A bulletin is acted on only while the page is shown.

### `QRollRefine`

It answers the roll's rows notice.

### `QRollShow`

The vita comes with the rows, so the same Author feeds both without a second read.
The workspace opening hands it the roll it already read.

### `QTallyRefine`

It also answers the workspace opening, so a fresh workspace shows no stale tally.

### `QGuildModeUpdate`

The two nested pages are pulled by contract ID, since their drivers own only what lies inside them.

### `QGuildPressCheck`

Print is allowed only while the gate says the colophon side is shown.

### `QGuildPressObserve`

The gate words the page with the Source legend.

### `QChronicleUndoObserve`

The caret is kept where it was.

## `QAutograph`

The driver of the Author edit area, a veneer page the guild page places.
It holds no state, since `CGuild` holds the autograph desk and the union verdict.
Every Observe hands one raw value to one gate, and every Refine paints what the panel answers.

### `QAutographIntroduce`

`CGuild` attaches the desk's own bulletins at build, with the marshal `QGuild` hands it.

### `QAutographTallyShow`

Both sides show the same counts, since both are written from the vita sheet the guild read.

### `QAutographModeUpdate`

The guild driver calls it whenever it writes its own mode.

### `QAutographStartRefine`

It answers `CGuildUnionCleared`, which the union raises when a tenure starts.
The union field and its list are emptied and the name takes focus.

### `QAutographUnionRefine`

The Authors the typed name matches are listed, for the user to fold this one into.

### `QAutographChoiceObserve`

`CGuildUnionSelect` folds the held Author into the clicked one.

## `QFellowItem`

One co-author row of the vita, with the Author's id, its name, and how many Sources credit both.
The count arrives worded by Core, so the row binds to text.

## `QOeuvre`

The middle column, with the oeuvre search field over it.
It lists every Source crediting the chosen Author, or every Source while none is chosen.
Choosing a row shows that Source in the colophon, through the guild's gate.

### `QOeuvreRefine`

It answers the oeuvre's rows notice and the workspace opening.
Conduct restores the vistas before the opening, so the list reads them restored.

## `QRollItem`

One roll row, with the Author's name, its worded source count, and its citation count.
The mark is resolved once from the icon key Conduct chose, because the uncredited row wears a different one.
The same row serves the union list of the edit area, because both list Authors with their source counts.
The chosen mark comes as a constructor parameter, so the mark has one kind of writer.

### `QRollItemMatch`

The chosen mark is left aside.
`QSplice` keeps the held rows when every pair matches, so their containers survive a refresh.

### `QRollItemApply`

The union row shares the part names, so the edit area attaches the same fill.

## `QVita`

The driver of the author reading, a veneer page the guild page places.
It draws the vita sheet it is handed and asks the engine for nothing.
The guild driver decides what is read and when the page is shown.

### `QVitaCitationObserve`

`CNavigationUsageOpen` opens the Example or the Entry of the clicked citing place.
