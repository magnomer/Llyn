# QUnion.cs

## `public sealed class QUnion`

The guild's author union, which folds the Author being written into a chosen one.
The author seam reads the Author the roll stands on, and the open seam reads the kept one afterwards.
The union seam is the window's merge question, worded by the two names.
The find, name and absorb seams carry the engine calls, so it names no port.
It is medium-free, so it takes `Q` until job44 sinks it into Conduct.

## `public bool QUnionShown`

The union section is shown while the autograph holds a stored Author, since a fresh one folds into nothing.

## `public IReadOnlyList<CCatalogAuthor> QUnionRead(string typed)`

The Authors the typed name matches, the one being written left out, at most a handful.

## `public void QUnionSelect(long? id)`

Folds the Author being written into the chosen one, behind the union seam, then reads the kept one.
A failure raises `QUnionFailed` with `Guild.MergeFailed`.

## `private bool QUnionConfirm(long kept)`

Asks the union seam with the held draft's name and the kept Author's name.
