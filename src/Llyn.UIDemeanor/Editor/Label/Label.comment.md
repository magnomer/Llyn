# Label

Label holds the Tag field of a card in the console.
A Tag may be written anew, so the field accepts anything typed and offers the stored Tags as a list.

## `BLabel`

This builds the one Tag field and hands out its keys.
A Tag shows as its text after a hash.
The field is wired to the caret's Tag trail and gates, so the console and the window decide alike.
The list is Conduct's `CProffer`, which narrows the stored Tags to the typed text.
So the console holds no list rule of its own.
A refused settle keeps its text in the entry, as the window does.
