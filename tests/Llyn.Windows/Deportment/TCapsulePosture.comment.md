# TCapsulePosture.cs

## `public sealed class TCapsulePosture`

Covers the window's GUI-only state over Deportment's Capsule under a real workspace folder.
Saved widths read back through a posture reopened on the same folder.
A reset drops every width and keeps each tab.
Unlinking reports a change once.
A window stored at once reaches the file, and a minimized window stores nothing.
