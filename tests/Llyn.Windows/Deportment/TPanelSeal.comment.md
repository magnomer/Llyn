# TPanelSeal.cs

## `public sealed class TPanelSeal`

Covers the maps the sealed panel draws between its Conduct shapes and the engine's.
The maps cast, so each mirror must declare its members in the engine's order.
These facts hold that order: every member maps to the one with the same name.
A filter hiding nothing maps to the engine's shared empty filter.
The hidden languages travel both ways unchanged.
These move to the portable suite once the panel sinks into Conduct.
