# TWindowSeal.cs

## `public sealed class TWindowSeal`

Covers the maps the sealed window draws between its Conduct shapes and the engine's.
The font role casts, so each mirror must declare its members in the engine's order.
A font with no size keeps the theme's size.
The settings and markdown maps carry the engine's values and verdicts unchanged.
These move to the portable suite once the window sinks into Conduct.
