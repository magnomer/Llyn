# TAtlas.cs

## `public sealed class TAtlas`

Covers the repertoire panel's situation list end to end on a real workspace.
Before a vista arrives the list reads nothing, and a blank title is named with the driver's untitled word.
A typed query narrows the rows, no order keeps the ordering, and a hidden language marks the list filtered.
A Situation a card cites counts that card, and the filter offers the catalog's languages.
The Situation map answers none for no Situation, and a stored one carries every field with its unknown mark.
These map tests moved here from the Windows suite once the list sank into Conduct.

## `private static CAtlas TAtlasPrepare(LEngine engine, CAtelier atelier)`

Builds the list over the atelier and a repertoire desk.
Its seams answer that the tab is in front and that every finish succeeds.

## `private static LSituation TAtlasSituationSave(LEngine engine, string title)`

Stores one Situation with the given title and nothing else.
