# TLibrary.cs

## `public sealed class TLibrary`

Covers the library panel's Conduct end to end on a real workspace.
Its rows, query, order and filter follow the vista, and nothing is read before a vista arrives.
A chosen row is marked and reported as the station, and a deleted one reports zero again.
The markup import asks the customs question once and stores under the declared rows.
A merge row appends to its target, so the declared mode reaches the engine unchanged.
A declined question stores nothing, and a malformed file shows the import failure.

## `private static CEnvoy TLibraryEnvoyCreate(`

An envoy that answers the customs question through `customs` and records every question it is asked.
