## `public sealed class TAtelierRespelling`

Covers the reflex rules the respelling helpers own, over a fake reflex port.
A reflex stands between slashes whenever its language is phonemic, and bare otherwise.
A reflex row answers ready to show, its text and fold mapped from the same engine call.
Each reflex row is marked as leading its run of one language.

## `private static LReflexDraft TAtelierReflexCreate(long id, string language, string text, string respelling)`

Builds one stored reflex row with one anchor, so a scan's copy of it shows.
