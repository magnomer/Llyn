# TParadigmView.cs
Hash: `41c5cdc7793e633c`

## `public sealed class TParadigmView`

Covers the Conduct records of the inflection box, with the engine's view faked at the paradigm port.
A real workspace holds the entry, so the reads meet the real wing and desk.

## `public void DisplayParadigmRead_ViewAnswered_MapsMarksAndHeaders()`

The lectern carries the engine's view into its records.
Marks, group and label keys, and header keys arrive unchanged.

## `public void SoundingParadigmRead_LostCell_AnswersHeldTip()`

The editor reads a lost cell as held, never as lost.
The cell retains the ellipsis placeholder and uses the `Paradigm.Held` tooltip key.

## `public void DisplayParadigmRead_ViewFails_AnswersNullViewAndNotice()`

A refused view read shows `Display.ParadigmReadFailed` and answers a null view.
