## `public sealed partial class TFault`

The second half of the synchronous fault sweep, holding the entry, display, panel and sound write gates.
It keeps `TFaultWrite.cs` within the line limit, and the rows join the sweep there.

## `private static IReadOnlyList<TFaultWrite> TFaultMarkRows =>`

A property, not a field, so the sweep's list reads it whatever the field order across files.
Port rows fault the port member the gate itself calls, over `TInterfaceConduct.TAtelierFaultCreate`.
Favorite and grasp rows read back the gate's own read, since it answers the written mark.
Tag and register creation read back the panel's row count, which a created row would raise.
The union select reads back whether the autograph shows, since a merge would close it.
Fold rows fault `LSettingsVault.LSettingsSave`, so the engine's own rollback is under test.
Their read-back is the settings field the gate writes, read from the engine.
Rank, rebuild and sound start rows read nothing back, since no gate read answers the engine work.
Sound start is reached through the wing open, the display resonate, and the panel open and resonate.
Other gates reach it only through these, so they hold no row of their own.
The display resonate and panel resonate rows open the entry first, so a chosen entry exists to reload.

## `private static long TFaultEntrySave(LEngine engine) =>`

Stores a plain English entry and answers its id, the entry every mark row writes to.

## `private static CEditor TFaultDeskOpen(TFaultStage stage)`

Builds an editor over the faulted atelier and opens a stored entry in a library vista.
Esteem, sounding and timbre gates act only on a stored entry, so a fresh draft would reach no port.

## `private static CWing TFaultWingOpen(TFaultStage stage)`

Builds a wing over the faulted atelier and opens a stored entry, so its display has a chosen entry.

## `private static CEnvoy TFaultConsentCreate(TFaultStage stage, string? wording) =>`

An envoy that answers every question yes and the coinage question with `wording`, unrecorded.
It records only failure keys, so the sweep sees the gate's notice alone.
