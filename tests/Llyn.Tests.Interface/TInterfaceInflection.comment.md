## `internal static class TInterfaceInflection`

The relays that build the inflection records of an entry.
That is the forms, the inflections, the paradigms and their rules, the features and the morphology values.
The paradigm rule resolve is relayed here too.
Each relay is transparent and carries no test logic of its own.
