# TInterfaceLexicon.cs

## `internal static partial class TInterface`

The relays for the core layer.
They build the lexical records a test hands to the engine and read the markup a test parses.
The grasp range check and star figure are relayed here too.
Each relay is transparent and carries no test logic of its own.
`TEntryDraftCreate` takes a reading, a recording and part-of-speech names, and builds the draft shapes around them.
`TSpeechNameRead` reads those names back off a loaded draft.
