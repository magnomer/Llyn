# TShelfSide.cs

## `public sealed class TShelfSide`

Covers which side of the sources tab the deportment stands on: the source areas or the entry areas.
A source row chosen shows the colophon and enables the bin.
A fresh request with a source chosen starts an entry under it and moves to the editor.
A fresh request with nothing chosen opens a source draft in the imprint.
Leaving a fresh entry returns to the chosen source in its read area.
The bin ignores the entry side and deletes the chosen source only from the source side.
