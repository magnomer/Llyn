# vocabulary.json

## file

Display vocabulary presets for Sanskrit.
The presets supply part of speech labels for entries.
People can still type labels absent from this list.
Each id is permanent after publication.
Renaming a preset keeps its id.
The shell shows these names in list order.
No inflection features or values are preset yet.

## exampleOrder

It chooses whether examples write particle or dependence first.

## registers

These are the registers the shell offers on a card.
People can still write a register absent from this list.

## parts

These are the available parts of speech.

## features and values

These lists have no presets yet.
